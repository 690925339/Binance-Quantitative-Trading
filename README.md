# QuantFlow 币安量化交易基础版

一个面向手机浏览器的 Binance Spot Testnet 交易测试台。当前版本优先验证最小技术闭环：公开行情、HMAC API 签名、账户余额和测试下单。策略只展示 MA5/MA20 观察信号，不会自动下单。

## 当前能力

- 手机 H5 仪表盘，支持 BTC、ETH、BNB、SOL 对 USDT 行情
- 15 分钟 K 线收盘价趋势和 MA5/MA20 观察信号
- Binance Spot Testnet API Key 连接与权限验证
- 测试网非零资产查询
- 市价测试订单校验，调用 `/api/v3/order/test`，不进入撮合
- API Secret 仅保存在 Node 进程内存，不写入浏览器存储、文件或日志
- 可配置策略中心：现货网格、马丁补仓、定期定投、双均线趋势、多空趋势三档，以及独立BTC动态多空策略
- 两套新闻组合策略：稳健新闻趋势组合、进取新闻趋势组合
- 分钟级新闻聚合，接入监管机构与项目官方一手来源，自动区分官方确认、多源印证和待确认
- 稳健组合支持 90% 准确率条件杠杆：至少 100 条已结算信号且低波动、低回撤时，目标敞口最多提高到 1.25×
- 90% 盈利月多空组合：85%动态市场中性相对动量叠加15%动态趋势仓位，2023年至今为38/42个盈利月
- 策略配置支持创建、编辑、启停观察、复制和删除，并持久化到 `data/config/strategies.json`
- 系统登录不开放注册；管理员可在后台新增、启停用户并重置密码，密码仅保存为 PBKDF2-SHA256 强哈希
- 同源 HttpOnly 会话、请求限流、请求体限制和基础安全响应头
- 零第三方运行依赖，Node.js 20+ 可直接启动

## 云端研究版

Sites 云端版本提供公开行情、实时 RSS 新闻、新闻可信度评估、策略观察配置以及已冻结的模拟盘快照。策略配置保存到托管数据库；首次访问时会从本地已验证快照建立线上基线，后续部署会比较周期和结算时间，只用更新的seed修复过期D1状态。

为避免任何 API Key 或 Secret 进入云端，云端版本不提供测试网账户连接、资产读取或测试订单校验。这三项功能继续仅在本地 Node 版可用。云端发布不代表策略会自动下单，也不构成收益承诺。

## 策略配置中心

当前提供十一类基础模板：

- 现货网格：模式、上下限、网格数量、计划投入、杠杆、止盈和止损均可配置。
- 马丁补仓：首单、安全单、回撤触发、金额倍率、间距倍率、补仓次数、资金上限和杠杆均可配置。
- 定期定投：单次投入、时间间隔、执行次数、组合止盈止损、资金上限和杠杆均可配置。
- 双均线趋势：K线周期、快慢均线、信号资金、最大仓位、单仓止盈止损和杠杆均可配置。
- 多空趋势组合：在六个主流交易对上进行多周期趋势投票，支持双向、仅做多或仅做空，并配置目标波动率及组合敞口。
- 多空趋势组合（收益增强）：信号与基准档相同，将目标波动、总敞口和单币敞口同步提高到 1.5 倍，默认 2×、最高 3× 杠杆。
- 多空趋势组合（高收益）：采用 2.0 倍风险预算，当前长期年化回测为 10.51%，但最大回撤接近 -28%。
- 90% 盈利月多空组合：每周做多相对强势币、做空相对弱势币，并用动态趋势仓位补充收益；历史盈利月比例不代表未来保证。
- BTC单币动态多空：只允许BTCUSDT，根据45/90/180日趋势投票开多、开空或空仓，叠加波动率目标、动态风险预算、1.5%月度亏损保护及BTC专属可信新闻冲突减仓。
- 稳健新闻趋势组合：价格信号占 75%，新闻信号占 25%；新闻可信度低于 75% 时不参与决策。
- 进取新闻趋势组合：价格信号占 55%，新闻信号占 45%；采用更高风险预算和更宽的回撤容忍度。

“启用”仅表示策略进入观察状态。常规模板允许配置 1–125× 杠杆，收益增强档、高收益档和新闻组合被硬限制在 3× 以内；杠杆当前仅用于按保证金估算最大名义敞口，现货 Testnet 不会据此开设杠杆仓位。后续合约执行器应读取同一份策略配置，并在真实下单前按交易对规则校验可用杠杆、价格步长、数量步长和最小名义价值。

## 快速开始

1. 安装 Node.js 20 或更新版本。
2. 首次启动前配置初始管理员（密码至少 10 个字符）：

   ```powershell
   $env:QUANTFLOW_ADMIN_USERNAME='admin'
   $env:QUANTFLOW_ADMIN_PASSWORD='请替换为高强度密码'
   $env:QUANTFLOW_ADMIN_DISPLAY_NAME='系统管理员'
   ```

3. 在项目目录运行：

   ```powershell
   npm.cmd start
   ```

   初始管理员创建后会以强哈希保存在已忽略的 `data/runtime/users.json`，后续启动不再依赖上述环境变量。

4. 手机与电脑在同一局域网时，可设置监听地址后启动：

   ```powershell
   $env:HOST='0.0.0.0'
   npm.cmd start
   ```

5. 电脑浏览器访问 `http://127.0.0.1:3173`，使用初始管理员登录。手机访问电脑的局域网 IP，例如 `http://192.168.1.10:3173`。

登录页不提供注册入口。管理员登录后可从“我的与连接 → 用户管理”进入后台，新增普通用户或管理员、启用或停用账号，以及重置密码。系统会阻止管理员停用自己或移除最后一名启用中的管理员。

## 配置 Binance Spot Testnet

1. 打开 [Binance Spot Test Network](https://testnet.binance.vision/) 并登录。
2. 创建测试网 HMAC API Key，按测试需要开启交易权限。
3. 在 QuantFlow 的“设置”页面填写测试网 API Key 与 Secret Key。
4. 连接成功后先检查“资产”，再到“交易”提交测试订单。

不要填写正式网 API Key。测试网资产没有真实价值，且 Spot Testnet 会不定期重置。

## 历史行情与回测数据

下载默认六个主流交易对从 2022-07-01 起的现货 1 小时 K 线；2022 年数据只用于指标预热，策略绩效从 2023-01-01 开始：

```powershell
npm.cmd run data:download
```

默认交易对为 `BTCUSDT、ETHUSDT、BNBUSDT、SOLUSDT、XRPUSDT、DOGEUSDT`，输出目录为 `data/market/spot/1h/`。每个 CSV 包含 UTC 时间、OHLC、基础资产成交量、成交额、成交笔数和主动买入量，并生成带 SHA-256 与连续性检查的 `manifest.json`。

自定义示例：

```powershell
node scripts\download-market-data.mjs --symbols BTCUSDT,ETHUSDT --interval 4h --start 2020-01-01 --end 2025-12-31
```

历史数据来自 Binance 公共正式市场行情接口，不需要 API Key，也不会访问或修改账户。回测时应使用 `open_time` 排序，并避免把尚未收盘的 K 线作为信号输入。

生成带覆盖范围、质量检查、数据源和日线汇总的 Excel 索引工作簿：

```powershell
npm.cmd run data:workbook
```

复核 CSV 行数、首末时间、SHA-256 和 UTF-8 无 BOM：

```powershell
npm.cmd run data:verify
```

运行含交易成本与保守持仓成本假设的多空策略回测：

```powershell
npm.cmd run backtest:long-short
```

比较固定信号下的四档风险预算：

```powershell
npm.cmd run backtest:return-profiles
```

策略中心分别保留基准、收益增强和高收益档：

| 档位 | 2025 收益 | 长期年化 | 最大回撤 | 最差滚动 365 日 |
| --- | ---: | ---: | ---: | ---: |
| 基准 1.0× | 4.06% | 5.50% | -14.97% | -11.41% |
| 收益增强 1.5× | 5.83% | 8.07% | -21.68% | -16.80% |
| 高收益 2.0× | 7.42% | 10.51% | -27.91% | -21.98% |

高收益档达到“长期年化超过 10%”的历史回测目标，但 2025 单年只有 7.42%，并不代表每个自然年都超过 10%。收益来自风险预算放大，不是信号命中率提高，也不能保证未来年化收益。

动态回撤减仓研究可复现运行：

```powershell
npm.cmd run research:high-return-control
```

该研究测试了 240 组因果回撤减仓参数。最小回撤的达标候选为年化 10.07%、最大回撤 -26.54%，但 747 天处于减仓状态且 2025 收益降至 5.43%，改善不足，因此没有替换透明的 2.0× 高收益档。

运行按完整自然月统计胜率的一致性过滤与动态杠杆研究：

```powershell
npm.cmd run research:monthly-win-dynamic
```

冻结参数在 2025-01 至 2026-06 的月胜率由 44.44% 提高到 50.00%，但年化只有 5.27%；进一步放宽杠杆敞口后月胜率回落到 44.44%、年化为 -4.67%。两者都没有达到发布门槛，因此仅保留研究能力，没有加入策略中心。

继续运行月度盈利锁定、趋势组合和横截面市场中性研究：

```powershell
npm.cmd run research:monthly-80
npm.cmd run research:all-conditions
```

准确率优先默认现为85%动态市场中性相对动量与15%动态趋势组合，在2025-01至2026-06取得17/18个盈利月（94.44%）、年化12.28%、最大回撤-11.71%。2023-01-01至2026-07-15累计收益94.49%、年化20.69%、最大回撤-22.96%；截至2026-06的42个完整月份中38个盈利（90.48%）。相对旧80/20配置，盈利月和年化提高，但验证回撤扩大0.41个百分点、长期回撤扩大1.15个百分点。它已作为配置观察档加入策略中心，但不会自动下单。由于同一验证区间已被多轮研究观察，正式使用前仍需新的前向纸面交易。实现、逐月收益和风险边界见 [90%盈利月多空组合](docs/monthly-accuracy-portfolio.md)。

策略现已支持以前一日恐惧与贪婪指数、20日全市场波动率、市场宽度动态配比和组合回撤减仓。官方情绪数据可用 `npm.cmd run data:fear-greed` 刷新。全部条件研究共评估440组候选；低回撤胜出参数在冻结验证为16/18个盈利月、年化10.03%、最大回撤-10.40%，没有超过准确率优先配置，因此动态参考、动态配比和组合减仓默认关闭，只保留为低回撤观察档。

### 每日纸面模拟盘

85/15组合可从启动日开始做前向纸面交易，不回填启动日前的假想收益。正式盘当前使用 `monthly-accuracy-continuous-derisk-v3`：横截面和趋势的月度盈利止盈均关闭；横截面月内收益达到0.75%、趋势达到1.00%后，各自仍按最新信号交易，但把实际敞口降到10%，趋势1.5%月度亏损保护继续保留。每日任务还维护一套完全独立的BTC单币模拟盘：

```powershell
npm.cmd run paper:daily
```

默认初始资金为10,000 USDT，可在首次启动前使用 `PAPER_INITIAL_CAPITAL` 或 `--initial-capital` 修改。模拟盘每天北京时间09:00使用此前完整UTC日线生成信号，并使用09:00刚闭合的一小时K线作为固定估值和模拟调仓价格。BTC单币盘首次建立时使用当时公开实时价作为模拟成交基线，不回填当天09:00至启动时之间的收益；以后与组合盘一起按09:00结算。状态与日报保存在已忽略的 `data/runtime/`，重复运行同一结算日不会重复扣费。2026-08-20的组合修复迁移不回写历史净值，从下一周期按最新完整信号重算仓位；持续交易降风险不是收益保证，达到阈值后仍可能亏损。

BTC单币参数固定沿用此前趋势设计：45/90/180日回看、至少2票同向、最低2%趋势强度、10%年化波动率目标、1至3倍动态风险预算，实际BTC绝对敞口上限为净值100%。它没有月度盈利止盈；月内盈利达到1%后仍保留10%信号敞口，月内亏损达到1.5%则本月停止。可信新闻只能降风险，不能反向开仓。精确执行时点历史验证为10/18个盈利月、年化3.84%、最大回撤-9.30%；2×成本验证年化3.42%。因此它只作为独立实验盘，不替换组合正式盘，也不作10%收益承诺。可复现实验：

```powershell
npm.cmd run research:btc-paper
```

2026-08-20的单日亏损复盘显示，当日组合净亏147.54 USDT（-1.47%）：趋势袖套的滞后多周期信号在市场同步反弹前形成净空，贡献约123.23 USDT亏损；横截面SOL多/XRP空的相对价差反向，贡献约24.31 USDT亏损。新闻快照为中性且没有同方向确认事件，因此没有足够证据干预价格信号。简单增加3至10日空头确认在冻结验证仅约4%至7%年化、双倍成本下为负，未被启用。

可复现本次正式执行时点研究：

```powershell
npm.cmd run research:paper-continuous-derisk
```

固定候选在2025-01至2026-06历史区间取得15/18个盈利月、15.64%年化、-14.86%最大回撤；双倍成本下为16/18、16.03%、-14.96%。无盈利锁基准同期只有9/18、6.11%、-33.24%。阈值来自本次探索性历史比较，该区间不是全新的未观察样本，真正验证从2026-08-21的前向模拟盘开始；历史结果不保证未来收益。

2026-08-25复盘确认8月21日的大额亏损来自单一“SOL多／XRP空”价差挤压，不是漏结算或记账错误；次日切换为“BNB空／XRP多”后恢复631.71 USDT。本轮因此不追溯改写正式盘，而是新增两个以v3为同源母版的独立影子：`shadow-continuous-diversified-v1`只把横截面持仓从每侧1币改为2币；`shadow-continuous-news-specific-risk-v1`只在标的专属新闻具有足够可信度、置信度和事件证据且与仓位冲突时减仓25%。旧v1影子账本保留但标记为历史归档，不再与v3混合做晋级比较。

分散候选的单变量复验中，2025-01至2026-06取得15/18个盈利月、14.08%年化和-8.13%最大回撤；2倍成本下为16/18、14.33%和-8.22%；全样本P95单币敞口由63.91%降至31.87%。对应区间既往已被查看，所以这些数字只允许新影子起跑，不能直接替换正式盘。可复现运行：

```powershell
npm.cmd run research:paper-continuous-diversification
```

Windows每日任务可通过以下命令安装；任务仅在当前用户已登录时运行并显示本地盈亏通知：

```powershell
npm.cmd run paper:install-task
```

网页“模拟盘”页面和 `GET /api/paper-portfolio` 会显示组合盘及独立BTC盘的当前净值、当日/累计盈亏、风险状态、持仓和最近日报；`GET /api/paper-portfolio/btc` 可单独读取BTC账本。页面会按北京时间09:00校验 `lastCycleDate`，账本落后时显示“数据延迟”但仍保留最后已结算收益。候选至少积累90天和3个完整月后才可诊断，达到更严格的540天和18个月门槛也只进入人工晋级复核。实现口径、接口和风险边界见 [每日纸面模拟盘](docs/paper-trading.md)。

针对模拟盘连续亏损暴露出的动态杠杆放大问题，可复现运行价差阈值邻域与成本压力研究：

```powershell
npm.cmd run research:paper-dispersion
```

截至2026-07-15，候选 `dispersionTarget=0.20` 在冻结验证区间保持17/18个盈利月，年化13.04%、最大回撤-10.17%，优于当前0.15阈值的12.34%和-11.71%；但在2×交易及持仓成本下，年化降至7.11%，未达到10%压力门槛。因此该候选没有加入模拟盘，冻结基准及当时已有影子均保持不变。

月度亏损保护与动态杠杆阈值的联合研究可运行：

```powershell
npm.cmd run research:paper-loss-guard
```

该研究只用2023-01至2024-12选择参数，再用2025-01至2026-06做冻结验证，共检查105组 `dispersionTarget`、横截面月度止损和成本组合。没有非基准方案在开发期同时保住21/24个盈利月、10%以上年化和回撤约束；4%至5%月度止损在冻结验证至多只有15/18个盈利月、约1.7%至4.5%年化，说明触发后整月空仓会错过月内修复。因此月度止损继续关闭，不新增影子候选。

继续运行调仓周期与最低换手缓冲研究：

```powershell
npm.cmd run research:paper-turnover
```

延长调仓周期会明显损失有效信号：9天周期虽降低约10%历史换手，但冻结验证年化降至9.55%、最大回撤扩大到-16.74%；14天周期只取得14/18个盈利月。保持7天周期并设置0.025至0.30最低换手门槛，历史累计换手最多仅下降约0.20%，对验证收益和回撤几乎没有影响。因此两条换手优化路线均未新增影子候选，最低换手功能保持默认关闭。

验证“横截面每侧2个标的”分散影子的历史表现：

```powershell
npm.cmd run research:paper-diversification
```

截至2026-07-15，每侧2个标的把单币最大模型权重从63.75%降至31.87%。在2025-01至2026-06冻结验证期取得16/18个盈利月、6.78%年化、12.73%波动率和-9.02%最大回撤；当前每侧1个标的基准为17/18、12.34%、17.26%和-11.71%。2023年至今分散方案累计收益33.99%、年化8.62%、最大回撤-12.42%，未达到10%年化准入目标。因此它继续作为降风险影子采样，不替换收益优先基准。

同一研究还验证了0%至60%的部分分散组合。分散30%和40%时，冻结验证年化分别为10.81%和10.27%，最大回撤改善到-10.81%和-10.51%，单币最大模型权重降至54.19%和51.00%；但两者在2023-01至2024-12开发期都只有19/24个盈利月（79.17%），低于预设80%门槛，且2×成本下验证年化分别只有8.43%和8.04%。因此部分分散也未新增影子候选，不能在看到结果后降低准入标准。

## 实时新闻与组合策略

“新闻”页面默认每 60 秒从多个 RSS 来源刷新一次，并为每条新闻提供：

- 利多、利空或中性方向；
- 方向判断置信度；
- 官方确认、多源印证或待确认状态；
- 基于官方匹配、来源等级和发布时间完整性的可信度；
- 关联交易对及经过新鲜度衰减后的新闻方向分数。

默认新闻源不需要 API Key。若配置 CryptoPanic，可增加聚合来源：

```powershell
$env:CRYPTOPANIC_API_TOKEN='your-token'
$env:CRYPTOPANIC_API_PLAN='growth'
npm.cmd start
```

新闻源不可用或评分低于策略门槛时，组合策略会自动退化为 100% 价格信号。详细评分公式、风险档位和接口见 [新闻组合策略说明](docs/news-composite-strategies.md)。

每日模拟盘新增独立的 `shadow-news-45-v1` 新闻增强影子。它不会修改当前冻结基准：每天09:00保存当时实际可见的不可变新闻快照，只有新闻同时达到75%可信度、65%方向置信度、至少1条非弱证据的官方确认且聚合方向分数不低于0.12时，才以45%新闻分数＋55%价格分数重新排列横截面多空候选；否则保持原价格排名。新闻影子从首次运行日开始采样，不使用今天抓到的标题反填历史，也不额外增加杠杆。

`shadow-news-risk-veto-v1` 是独立的前向风控试验：可信度至少65%、方向置信度至少50%、文章数至少3且方向分数绝对值不低于0.15的中等质量新闻，不能改变多空标的；只有其方向与已选仓位冲突时，才把横截面多空两侧同时缩减25%。它用于验证新闻是否适合先做风险刹车，而不是通过降低正式交易门槛强迫新闻产生方向信号。

`shadow-news-specific-risk-v1` 使用完全相同的风控门槛和75%敞口比例，但风险分数只采用标题明确关联该币种的新闻，排除仅标记为泛市场的消息。它与原新闻风控构成单变量前向A/B：如果专属版本减少错误降敞口且不恶化回撤，才有资格在足够样本后进入人工复核；不会用当前新闻反填历史或直接替换正式策略。

新闻采集只接受北京时间09:00至09:15的同周期实时快照；失败会强制刷新重试并留下审计，过期、错周期或缺失快照一律回退纯价格。新闻服务同时记录按事件去重的同方向官方确认/独立多源证据，但不会追溯修改已经启动的冻结影子参数。

稳健组合会把每个非观望信号按 7 天窗口写入本地 `data/runtime/signal-accuracy.json`。同一交易对的上一条信号结算前不会重复计数；最近 100 条准确率达到 90%、最近 20 条达到 85%、Wilson 95% 下界达到 82%、年化波动不超过 8%、当前回撤不超过 5% 时，才把目标敞口乘以 1.25。任何门槛失效立即恢复 1×。该运行数据已加入 `.gitignore`，不会作为回测结果提交。

## 安全边界

这是可本地测试的基础版，不是可直接经营的多用户生产系统：

- 目前没有用户注册、登录、数据库和多租户隔离。
- API 凭证只在单个 Node 进程的内存中保存，默认 30 分钟过期，服务重启即清空。
- 局域网测试使用 HTTP；对公网部署前必须配置 HTTPS、安全的反向代理与可信主机。
- 正式交易前必须加入持久化加密、密钥轮换、IP 白名单、二次确认、订单幂等、仓位/损失限制、审计日志、告警与熔断。
- Binance 返回 5xx 或超时时，订单执行状态可能未知；真实下单系统必须主动查询订单状态，不能简单重试。

## 下一阶段建议

1. 引入用户系统、PostgreSQL 与 KMS/信封加密，建立真正的多用户密钥隔离。
2. 把策略定义、行情采集、回测、风控、执行器拆成独立边界。
3. 先实现回测和纸面交易，再开放测试网自动交易。
4. 增加最大仓位、单笔风险、日亏损、冷却期、幂等键和全局熔断。
5. 最后才通过显式环境开关接入正式网，并保留人工确认和一键停机。
