# 80%第二轮研究与资金费率组合

## 结论

第二轮尝试了两条独立路线，但仍没有得到“成本后胜率不低于 80%、正期望、年化 5%–10%、最大回撤不超过 15%”的可发布策略。

| 路线 | 达到的最高正确率 | 成本后结果 | 状态 |
| --- | ---: | ---: | --- |
| 趋势中的回撤入场 | 开发期交易胜率 75.00% | 利润因子 0.79，年化 -6.68% | 拒绝 |
| 资金费率方向预测 | 验证期 90.41% | 完整周期胜率 12.50%，年化 -0.73% | 拒绝 |

资金费率的正负方向确实具有较强持续性，但“方向猜对”不等于“策略赚钱”。现货和永续开平仓成本、滑点以及现货/永续基差变化会吞噬资金收入，因此该路线不能因为方向正确率超过 80% 就晋级。

## 路线一：趋势回撤交易

规则为：

1. 用长期收益和长期均线确定多空趋势。
2. 上涨趋势中等待短期回撤后做多；下跌趋势中等待短期反弹后做空。
3. 信号日收盘后生成决策，下一日开盘入场。
4. 使用止盈、止损和最长持有期退出。
5. 同一根日 K 同时触发止盈和止损时，保守地按止损成交。
6. 扣除单边 7 bps 交易成本和每日 0.5 bps 持仓成本后，净收益大于零才算正确。

总共只试验 44 组预先限定参数，避免无限扩展参数空间。最高胜率组合为：

| 指标 | 结果 |
| --- | ---: |
| 交易数 | 372 |
| 胜率 | 75.00% |
| 胜率 95% Wilson 下界 | 70.36% |
| 做多/做空交易 | 244 / 128 |
| 利润因子 | 0.79 |
| 单笔期望 | -0.27% |
| 年化收益 | -6.68% |
| 最大回撤 | -14.05% |

它展示了典型的“高胜率、低盈亏比”陷阱：平均盈利约 1.35%，平均亏损约 5.15%，所以 75% 胜率仍然亏损。

## 路线二：市场中性资金费率

正资金费率时，永续多头向空头支付资金费率。策略在观察到连续正资金费率后建立：

```text
现货：做多等量基础资产
USDⓈ-M 永续：做空等量合约
```

两个方向使用相同基础资产数量，以降低价格方向暴露。每个完整持仓周期的损益为：

```text
净损益 = 收到的资金费率
       + 现货价格损益
       - 永续价格损益
       - 现货手续费
       - 永续手续费
       - 两条腿滑点
```

参数只在 2023-07-01 至 2024-12-31 开发区间选择，然后冻结到 2025-01-01 至 2026-06-30。总参数数为 18 组：

- 连续观察 2、3 或 6 个结算周期；
- 平均资金费率至少 0.005% 或 0.01%；
- 弱信号连续 1、3 或 6 个周期后退出。

冻结参数为连续观察 6 个周期、平均资金费率至少 0.01%、连续 6 个弱周期后退出。名义金额为组合资金的 80%。成本假设为：现货单边 0.10%、永续单边 0.05%、每条腿单边滑点 0.02%。实际费率因账户等级、挂单/吃单和交易对而不同。

## 数据与质量

资金费率和标记价格来自 Binance 官方月度 USDⓈ-M 公共数据归档。BTC、ETH、BNB 各有 3,831 条源资金结算记录，其中各有 3,825 条与标记价格精确对齐；每个交易对有 6 条因官方标记价格归档缺口被丢弃，没有进行插值。现货价格使用仓库内同一小时的现货开盘价，避免使用该小时结束后的信息。

数据文件位于 `data/market/funding/`，清单记录 SHA-256、源记录数、未匹配数和重复时间数。

## 发布门槛

资金策略必须同时满足：

| 指标 | 门槛 |
| --- | ---: |
| 成本后完整周期胜率 | ≥ 80% |
| 胜率 95% Wilson 下界 | ≥ 60% |
| 完整周期数 | ≥ 30 |
| 下一资金费率方向正确率 | ≥ 80% |
| 利润因子 | ≥ 1.20 |
| 年化收益 | 5%–10% |
| 最大回撤 | 不低于 -15% |

任何一项失败都保持研究状态。

## 实盘边界

当前代码仍只做回测，不会自动建仓。真实资金费率套利还必须处理现货和永续两条腿成交不同步、合约保证金隔离、强平风险、自动减仓、标记价格异常、资金费率间隔动态变化和交易所接口故障。现货盈利不能自动阻止永续空头腿被强平，必须通过跨保证金或主动划转单独管理。
