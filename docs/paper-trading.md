# 每日纸面模拟盘

该模拟盘从实际启动日开始记录85%横截面市场中性动量与15%动态趋势组合，不回填启动日前收益，也不会调用任何下单接口。

## 时间与行情口径

- 时区：Asia/Shanghai。
- 每日结算时间：09:00。
- 信号数据：结算日前已经完整结束的UTC日线。
- 模拟估值和调仓价格：09:00刚闭合的 `00:00–00:59 UTC` 一小时K线收盘价。
- 行情接口：Binance公开市场数据接口，不需要API Key。
- 月中启动的首月标记为不完整月份，不纳入盈利月准确率；下一个自然月才是首个完整前向月份。

## 资金与成本

首次启动默认本金为10,000 USDT。策略配置页面中的2×杠杆只代表保证金容量，不会再次乘到策略权重上。

模拟盘沿用回测成本：

- 每单位换仓成本：7 bps。
- 每日持仓成本：总绝对敞口的0.5 bps。
- 组合首次从现金分配到85/15两个仓位时，另计7 bps配置成本。

首次运行只建立仓位基线，因此价格盈亏为0，但会显示建仓模型成本。

## 运行

手工结算：

```powershell
npm.cmd run paper:daily
```

显示Windows通知：

```powershell
npm.cmd run paper:daily:notify
```

安装每天09:00运行的Windows任务：

```powershell
npm.cmd run paper:install-task
```

任务名称为 `BinanceQuantPaperDaily0900`，使用当前Windows用户、最低权限和交互式登录方式。用户未登录时不会显示通知；重新登录或网络恢复后，任务配置的“尽快补跑”会尝试补算遗漏日期。

## 持久化与幂等

- 主状态：`data/runtime/monthly-accuracy-paper.json`
- 最新日报：`data/runtime/paper-reports/latest.md`
- 每日JSON：`data/runtime/paper-reports/YYYY-MM-DD.json`
- 新闻决策快照：`data/runtime/paper-news-snapshots/YYYY-MM-DD.json`

状态通过临时文件和原子重命名写入，并使用跨进程锁避免两个任务同时结算。已经处理过的日期不会重复计算盈亏、成本或换仓。

每日结算会先写主账本，再生成日报和复盘产物。即使进程在产物写入之间中断，下一次运行也会从主账本的 `lastCycleDate` 幂等恢复；主账本的原地状态更新同样会强制原子落盘。

## 持续复盘与影子优化

基准策略ID固定为 `monthly-accuracy-85-15-v1`。模拟盘启动后不会根据单日盈亏直接改参数；当前同时运行四个不下单的影子候选：

- `shadow-stable-cash-85-v1`：85%横截面＋15%现金，只验证现金缓冲是否能降低回撤。
- `shadow-diversified-cross-2-v1`：保持85/15资金分配，只把横截面多空腿从每侧1个标的扩到每侧2个，验证分散化是否能降低单一价差风险。
- `shadow-news-45-v1`：保持原资金、成本和杠杆边界，只在新闻通过高可信与官方确认门槛时，以价格55%＋新闻45%调整横截面排名。
- `shadow-news-adaptive-v1`：沿用相同新闻硬门槛，但按可信度、方向置信度和方向强度把实际新闻权重限制在0%至45%，与固定45%影子做前向对照。

候选从启用日建立自己的模拟基线，不回填此前行情。候选配置一旦启动即冻结；任何参数变更必须使用新的策略ID重新采样，失败候选也计入试验次数。

每日复盘包括：

- 各币种价格变化、调仓前横截面/趋势权重和价格盈亏贡献。
- 横截面、趋势两个子策略的价格贡献、交易成本、持仓成本和净贡献。
- 最大拖累、最大正贡献、仓位集中、趋势对冲及成本拖累诊断。
- 基准最近7、30、90天的净收益、回撤、最差日、盈利日比例和成本。
- 影子候选与基准共同前向日期上的收益、回撤、波动率、ES95和完整月表现。
- 新闻增强影子的快照时间、新闻源可用数、合格币种、实际新闻权重、回退原因和调整后的多空排名。

单日盈利比例只叫“盈利日比例”，不等同于方向预测准确率。

### 候选状态机

- `collecting`：不足90个共同日报、3个完整月或数据覆盖不足99.5%，只能积累数据。
- `reviewable`：达到90天和3个完整月，可以诊断但不能晋级。
- `promotable`：至少540个共同日报和18个完整月，并同时达到盈利月不低于80%（至少15/18）、Wilson 95%下界不低于60%、成本后暂估年化不低于10%、相对基准的7日块bootstrap经多重试验修正后显著、最大回撤/波动率/ES95/敞口均通过门槛。
- `reject`：触发15%回撤、5%最差日、150%总敞口等硬风控，或在早期复盘后收益与回撤同时明显落后基准。

`promotable` 只表示进入人工复核，系统不会自动替换基准，也不会为弥补收益不足而自动增加杠杆。年化10%和80%盈利月是筛选目标，不是对未来结果的保证。

### 新闻增强影子

新闻增强影子只在每天北京时间09:00结算任务真正读取到的新闻上做决策。快照文件保存抓取时间、来源状态、标题发布时间、可信度、确认状态和分币种聚合结果；发布时间晚于抓取时点的消息会被排除。首次启动如果错过09:00后的15分钟采集窗口，会顺延到下一个结算日，不会拿稍后新闻按09:00价格建仓；已经启动后补算缺失日期时，如果当日没有保存的新闻快照，就退回价格信号，不允许用之后看到的新闻倒填。

新闻准入同时要求：

- 新闻服务状态为 `live`。
- 分币种聚合可信度不低于75%，方向置信度不低于65%。
- 至少1条官方确认消息同时通过可信度和方向置信度门槛，且证据强度不是 `weak`。
- 新闻聚合方向分数绝对值不低于0.12。

通过后，横截面候选排名分数为：

```text
ranking_score = 55% × normalized_price_score + 45% × news_score
```

固定权重影子继续使用上述45%口径。质量自适应影子对每个合格币种计算：

```text
quality = credibility × confidence × min(1, abs(news_score) / 0.50)
effective_news_weight = 45% × quality
ranking_score = (1 - effective_news_weight) × normalized_price_score
              + effective_news_weight × news_score
```

刚超过准入线的消息只获得较小权重；可信度、方向置信度和方向强度同时提高时才逐步接近45%。两个新闻影子都不会提高动态杠杆上限。

没有通过的币种新闻分数按0处理；如果所有币种都不合格，则整套影子使用原价格排名。新闻只改变候选排序，不提高动态杠杆上限，也不绕过月度止盈和成本模型。

2026-07-24的实时源核验中，13个来源有10个可用，但整体可信度71%、方向置信度48%，没有币种通过准入，因此按规则应退回价格信号。核验还发现通用单词 `surge` 会把“Bitcoin slides while oil and bond yields surge”误判为利多；标题规则现已将币价下跌、战争/冲突以及油价或债券收益率上冲识别为风险偏好利空，并有自动化用例防止回归。

现有RSS只能从启用日开始积累可审计快照，因此当前不能声称新闻影子已经通过历史回测。它仍须满足与其他影子相同的90天/3个月诊断门槛和540天/18个月人工晋级门槛。

### 动态杠杆价差阈值研究

连续亏损日若主要来自单一横截面价差，优先检查动态杠杆是否在价差扩大时上升过快。以下命令会固定其余配置，只测试 `dispersionTarget` 的0.15至0.25邻域，并同时运行1×、1.5×和2×交易及持仓成本：

```powershell
npm.cmd run research:paper-dispersion
```

研究输出：

- `data/runtime/paper-research/dispersion-latest.json`
- `data/runtime/paper-research/dispersion-latest.md`

截至2026-07-15，0.20候选在2025-01至2026-06冻结验证取得17/18个盈利月、13.04%年化和-10.17%最大回撤；当前0.15基准为17/18、12.34%和-11.71%。但是0.20候选在2×成本下年化只有7.11%，低于10%压力门槛，所以准入结果为未通过，不启动新影子ID。失败结果和试验次数也必须保留，不能在看到结果后降低门槛。

### 月度亏损保护联合研究

```powershell
npm.cmd run research:paper-loss-guard
```

该研究联合测试0.15至0.21的动态杠杆离散度阈值、关闭或1%至5%的横截面月度止损，以及1×、1.5×、2×交易和持仓成本。参数只能根据2023-01至2024-12开发区间选择，2025-01至2026-06冻结验证结果不参与选择。

截至2026-07-15，共105组试验中没有非基准配置能在开发期同时达到基准的21/24个盈利月、10%以上年化和-20%以内回撤。4%至5%月度止损在冻结验证至多只有15/18个盈利月，年化约1.7%至4.5%；月度锁定一旦触发会在余下月份保持空仓，因此容易错过月内反弹。该方向不启动影子候选，横截面 `monthlyLossLimit` 继续为 `null`。

### 调仓周期与最低换手研究

```powershell
npm.cmd run research:paper-turnover
```

该研究分两步检查换手成本：

- 将横截面调仓周期从当前7天扩展到5、6、8、9、10、12和14天。
- 保持7天周期，仅当目标仓位总变化达到0.025至0.30的最低换手门槛时执行调仓。

候选先按2023-01至2024-12开发区间筛选，再用2025-01至2026-06冻结区间做准入验证，并运行1×、1.5×和2×成本压力。9天周期虽然降低约10%累计换手，但验证年化只有9.55%、最大回撤-16.74%；14天周期验证盈利月降至14/18。最低换手门槛最多只把累计换手从214.19降至213.76，未达到10%降幅要求。两条路线均不启动新影子候选。

`minimumRebalanceTurnover` 的默认值为0。它只提供可复现研究能力；月初建仓、月度锁定平仓、参考风险缩放和显著仓位变化不受小额换手缓冲阻止。

研究输出：

- `data/runtime/paper-research/turnover-latest.json`
- `data/runtime/paper-research/turnover-latest.md`

### 分散横截面持仓历史验证

```powershell
npm.cmd run research:paper-diversification
```

该研究固定85%横截面＋15%趋势、10日相对动量、7天调仓、动态杠杆和月度锁定，只比较横截面每侧持有1、2、3个标的，并运行1×、1.5×和2×成本。每侧2个标的就是当前 `shadow-diversified-cross-2-v1` 的冻结参数。

截至2026-07-15的历史结论：

| 指标 | 每侧1个基准 | 每侧2个分散影子 |
| --- | ---: | ---: |
| 冻结验证盈利月 | 17/18 | 16/18 |
| 冻结验证年化 | 12.34% | 6.78% |
| 冻结验证波动率 | 17.26% | 12.73% |
| 冻结验证最大回撤 | -11.71% | -9.02% |
| 2023年至今累计收益 | 94.49% | 33.99% |
| 2023年至今年化 | 20.69% | 8.62% |
| 2023年至今最大回撤 | -22.96% | -12.42% |
| 单币最大模型权重 | 63.75% | 31.87% |

分散影子成功降低集中度、波动和回撤，但开发期只有18/24个盈利月、年化9.99%，冻结验证和全历史年化也都低于10%。在2×成本下冻结验证年化进一步降至5.42%。因此历史准入为未通过：继续保留其前向影子数据用于评估降风险价值，但不能替换当前收益优先基准，也不能通过加杠杆补足收益。

研究同时按10%步长测试将0%至60%的横截面资金分配给每侧2个标的、其余资金保留每侧1个标的。30%至40%部分分散在冻结验证仍保持10%以上年化，并把回撤和单币集中度同时降低：

| 30% | 19/24 | 16/18 | 10.81% | -10.81% | 17.19% | 54.19% |
| 40% | 19/24 | 16/18 | 10.27% | -10.51% | 16.00% | 51.00% |

这些组合的开发期盈利月都是79.17%，没有达到预设80%；30%和40%方案在2×成本下验证年化也只有8.43%和8.04%。因此不创建新的混合影子ID。该失败仍计入30组总试验数量，不能在看到冻结结果后改用更宽松门槛。

### 自适应宽度与置信度杠杆研究

```powershell
npm.cmd run research:paper-adaptive-breadth
```

该研究新增默认关闭的通用能力：以3/5/10/20/30日多周期排名稳定度、头尾分数差和20日市场波动判断信号质量；信号不稳定时可以切换为每侧2个标的、降低总敞口、收紧杠杆或限制单币权重。正式基准没有启用这些参数。

本轮预先定义96组参数，只用2023-01至2024-12开发区间选择候选，再读取2025-01至2026-06冻结验证。开发期选中的温和置信度杠杆候选取得21/24个盈利月、29.39%年化；但冻结验证只有16/18个盈利月、7.68%年化和-10.62%最大回撤。它虽然把P95单币权重从75.00%降至59.77%，但收益明显低于基准的12.34%；2×成本下验证年化8.10%，同样未达到10%门槛。

因此不创建自适应价格影子ID。通用计算和审计字段保留用于复现实验，`adaptiveBreadthEnabled` 默认保持关闭；不能从已看过的冻结验证结果中改挑另一组参数。

研究输出：

- `data/runtime/paper-research/adaptive-breadth-latest.json`
- `data/runtime/paper-research/adaptive-breadth-latest.md`

### 12币扩展交易池验证

```powershell
npm.cmd run research:paper-expanded-universe
```

该研究使用隔离目录 `data/runtime/expanded-universe/spot/1h`，在六币冻结交易池之外加入ADA、LINK、AVAX、DOT、LTC和TRX。数据覆盖2022-07-01至2026-07-22，共12个交易对；扩容行情不会覆盖模拟盘的六币历史数据。

研究仍固定85%横截面＋15%趋势和其余策略参数，只比较扩大候选排名池后的每侧1、2、3个标的、0%至60%部分分散，并运行1×、1.5×和2×成本。结果显示扩容不是有效的集中度修复：

| 指标 | 六币冻结基准 | 12币每侧2个 | 12币每侧2个＋固定高波动过滤 |
| --- | ---: | ---: | ---: |
| 开发盈利月 | 23/24 | 20/24 | 20/24 |
| 冻结验证盈利月 | 17/18 | 14/18 | 13/18 |
| 冻结验证年化 | 12.34% | -0.18% | 6.07% |
| 冻结验证最大回撤 | -11.71% | -21.63% | -11.43% |
| 2023年至今年化 | 20.69% | 7.22% | 13.94% |
| 2×成本冻结验证年化 | 未作为本轮对照 | -1.79% | 2.94% |
| 单币最大模型权重 | 63.75% | 31.87% | 31.87% |

扩容候选的主要异常月是2025-03，单月收益-18.95%；同月六币基准为+0.26%。这说明新增标的改变了头尾排名，更多持仓同时纳入了较弱信号，并非简单的“持仓越分散越稳”。扩容后每侧1个标的在验证期也仅有0.34%年化，进一步证明问题来自交易池改变，而不只是每侧持仓数量。

固定风险过滤器沿用既有六币研究在开发期选出的规则：使用当时可见数据计算20日市场年化波动，超过60%时将横截面仓位降为零，趋势子策略不变。它把2025-03损失降到-7.53%，但同时错过2025-11和2025-12的横截面收益，最终只有13/18个盈利月。该规则能降低尾部风险，不能恢复扩容信号质量；不得通过后验降低波动阈值或加杠杆强行补足收益。

本轮33组试验全部计入报告，扩容候选、部分分散和固定风险过滤器均未通过既定准入，因此不创建新影子ID。

研究输出：

- `data/runtime/paper-research/expanded-universe-latest.json`
- `data/runtime/paper-research/expanded-universe-latest.md`

复盘产物：

- `data/runtime/paper-review.json`
- `data/runtime/paper-reviews/latest.md`
- `data/runtime/paper-shadow/<profile-id>.json`

## 页面和接口

- 网页入口：首页“模拟盘”。
- `GET /api/paper-portfolio`：当前净值、累计盈亏、最大回撤、持仓与日报。
- `GET /api/paper-portfolio/reports?limit=30`：最近已经封账的日报。
- `GET /api/paper-portfolio/review`：最新损益归因、滚动复盘、影子候选状态和晋级门槛。

页面只读取持久化结果；即使浏览器或本地Web服务没有保持打开，Windows任务仍可独立结算。

## 风险边界

这是固定成本假设下的纸面结果，不包含永续合约实际资金费率、基差、盘口深度、部分成交、强平或多腿失败。纸面盈利不能直接视为可实现收益，至少需要6至12个月新的前向样本后再决定是否进入小额实盘评估。
