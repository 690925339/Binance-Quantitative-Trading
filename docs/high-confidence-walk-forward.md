# 高置信度多空策略与 80% 回测门槛

## 结论

本模块把“80% 都是正确的”定义为：在完全冻结参数的样本外区间，组合方向命中率和单币方向命中率都不低于 80%。没有信号的窗口不算正确，也不允许通过删除亏损交易、缩短亏损统计或使用未来数据提高结果。

当前仓库数据没有通过该目标。开发区间的最佳稳健候选为 72.73%，冻结参数后的样本外组合命中率为 45.00%，单币命中率为 41.46%，年化收益为 -17.36%。因此候选策略不得替换当前多空趋势策略，也不得进入自动执行。

80% 是研究和发布门槛，不是对未来收益或命中率的保证。

## 数据分区

| 用途 | 区间 | 是否允许调参 |
| --- | --- | --- |
| 开发区间 | 2023-07-01 至 2024-12-31 | 是 |
| 冻结参数样本外区间 | 2025-01-01 至 2026-06-30 | 否 |

候选参数只能根据开发区间选择。样本外结果一旦被查看，就不能继续用该区间调整参数；下一轮研究需要等待新的行情数据，或者预先登记一套新的规则后进入纸面交易。

## 信号与正确性

每个交易对使用多周期风险调整动量：

```text
normalized_momentum(L) = log(close(t) / close(t-L))
                         / (daily_volatility × sqrt(L))
```

多个周期方向一致时置信度上升；低于最低置信度的窗口空仓。组合可选择置信度最高的若干交易对，并支持做多和做空。

预测只使用决策日及以前的已收盘价格。预测窗口结束后，按以下净方向收益判断正确性：

```text
net_directional_return = direction × future_return
                         - 双边交易成本
                         - 持仓成本
```

只有 `net_directional_return > 0` 才算正确。组合命中率按每个有效决策窗口计算；单币命中率按每个交易对预测计算。预测窗口与决策间隔相同，避免大量重叠标签夸大样本量。

## 发布门槛

候选策略必须同时满足：

| 指标 | 门槛 |
| --- | ---: |
| 样本外组合方向命中率 | ≥ 80% |
| 样本外单币方向命中率 | ≥ 80% |
| 有效组合决策数 | ≥ 24 |
| 单币预测数 | ≥ 36 |
| 做多预测数 | ≥ 8 |
| 做空预测数 | ≥ 8 |
| 信号覆盖率 | ≥ 10% |
| 年化收益 | 5%–10% |
| 最大回撤 | 不低于 -15% |

门槛是全部通过，不是只挑命中率。代码还报告命中率的 95% Wilson 下界，让少量样本得到的高比例不会被误解为稳定能力。

## 当前结果

开发区间从 1,728 组预先限定的候选参数中选择。候选必须满足开发期最少决策、多空样本、覆盖率、收益和回撤约束，然后优先比较命中率的 95% Wilson 下界。

冻结参数为：

```json
{
  "lookbackDays": [30, 90, 180],
  "predictionHorizonDays": 21,
  "decisionIntervalDays": 21,
  "minimumConfidence": 0.25,
  "marketWeight": 0,
  "requireMarketConfirmation": false,
  "maxSelectedAssets": 3
}
```

| 指标 | 开发区间 | 样本外区间 |
| --- | ---: | ---: |
| 组合方向命中率 | 72.73% | 45.00% |
| 命中率 95% 下界 | 51.85% | 25.82% |
| 单币方向命中率 | 57.14% | 41.46% |
| 有效决策数 | 22 | 20 |
| 信号覆盖率 | 84.62% | 80.00% |
| 做多预测数 | 32 | 15 |
| 做空预测数 | 10 | 26 |
| 年化收益 | 62.70% | -17.36% |
| 最大回撤 | -19.40% | -33.08% |

结果显示开发期表现没有延续到样本外，这是典型的参数不稳定现象。继续根据 2025–2026 结果挑选参数会污染验证集，而不是提高策略真实能力。

## 新闻信号边界

当前实时新闻模块没有保存 2023 年以来每个历史时点当时可见的完整新闻快照，因此本回测不加入新闻。把今天的 RSS 内容回填到历史行情会产生时间穿越。后续必须先持续归档新闻原文哈希、来源、抓取时间、发布时间、情绪判断和当时模型版本，再进行真正的新闻样本外回测。

## 运行

```powershell
npm.cmd run backtest:high-confidence
```

核心实现位于 `src/high-confidence-walk-forward.js`，自动化测试位于 `test/high-confidence-walk-forward.test.js`。
