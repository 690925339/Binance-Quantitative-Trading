# 90% 盈利月多空组合

## 指标定义与结论

“80% 准确率”在本策略中固定定义为：完整自然月的组合净收益大于 0 的月份，占全部完整月份的比例。收益等于 0 的月份不算盈利月。验证区间共有 18 个月，因此至少需要 15 个盈利月才能达到 80%。

当前冻结组合在 2025-01 至 2026-06 的历史结果为：

| 指标 | 结果 |
| --- | ---: |
| 盈利月 | 17 / 18 |
| 盈利月比例 | 94.44% |
| 年化收益 | 12.28% |
| 最大回撤 | -11.71% |
| 亏损月 | 2026-01 |

这些数字通过当前历史发布门槛，但不是未来月份盈利概率或收益保证。此前研究已经多次观察过同一验证区间，而且本轮是在旧趋势模型失败后增加了新的横截面策略家族，因此该区间不能再视为完全未触碰的最终测试集。策略中心只把它作为观察档；进入自动执行前必须积累新的前向纸面交易月份。

## 组合结构

最终组合使用两个独立资金仓位：

| 仓位 | 权重 | 主要作用 |
| --- | ---: | --- |
| 横截面市场中性动量 | 85% | 获取币种相对强弱收益，降低对全市场涨跌方向的依赖 |
| 动态多空趋势 | 15% | 在持续单边行情中提供补充收益，并按趋势强度调整风险预算 |

组合每日收益按两个仓位的资金权重相加，两个仓位分别维护自己的月度盈利锁定状态。权重只在开发区间选择，验证区间不重新调参。

### 85% 横截面市场中性仓位

每天计算六个交易对最近 10 日收益率，每 7 天重新排序：

1. 做多相对收益最高的 1 个交易对。
2. 做空相对收益最低的 1 个交易对。
3. 多空两侧名义金额各占该仓位总敞口的一半，基础总绝对敞口为该仓位净值的 50%。
4. 相对最强与最弱交易对的10日收益率差越大，风险倍率从1×线性提高，价差达到15%时触及3×上限；该仓位总绝对敞口最高150%。
5. 当月累计收益达到 1.0% 后，下一交易日平仓并空仓至下月。

这里的“市场中性”仅表示多空名义金额相等，不代表贝塔、资金费率、基差、流动性和强平风险完全中性。

### 15% 动态趋势仓位

趋势仓位使用 45、90、180 日收益率投票，至少两票同向才参与。目标年化波动为 10%，单币绝对敞口上限为 30%，总绝对敞口上限为 100%。动态风险倍率为：

```text
dynamic_leverage = 1 + 2 × min(1, average_trend_strength / 20%)
```

倍率范围为 1×–3×，但它只作用于15%的趋势仓位，且不能突破仓位自身总敞口上限。趋势仓位当月盈利达到 1.25% 后锁定，亏损达到 1.5% 后停止至下月。85%市场中性仓位在3×动态倍率下的理论总敞口为127.5%，再加15%趋势仓位，组合配置上限取143%。

## 回测设计

行情使用仓库内 `BTCUSDT、ETHUSDT、BNBUSDT、SOLUSDT、XRPUSDT、DOGEUSDT` 的 1 小时现货数据，并在每个 UTC 自然日取最后一根收盘价。只保留六个交易对共同存在的日期。原始行情从2022-07-01开始，其中2022年仅用于180日趋势指标预热；新增绩效范围严格从2023-01-01开始。当前报告截止到最新完整UTC日2026-07-15，未完成的2026-07月份不计入盈利月比例。

- 开发区间：2023-08 至 2024-12，共 17 个完整月份。
- 冻结验证：2025-01 至 2026-06，共 18 个完整月份。
- 每单位单边换仓成本：7 bps。
- 每日持仓成本：总绝对敞口的 0.5 bps。
- 所有信号只使用当日已经收盘的数据，仓位承担下一日收益。
- 月度止盈或止损在当日收盘确认，最早在下一交易日平仓。

研究共评估 1,890 组趋势月保护参数、7,200 组横截面参数和 347 个开发期等权趋势组合。第一阶段得到80/20冻结组合；第二阶段比较0%–25%趋势权重，并加入全部市场状态条件。准确率优先配置最终采用85/15。

## 市场状态参考层

参考层只缩放市场中性仓位或调整两个仓位的资金配比，不改变多空标的排序，包含三类参数：

1. **恐惧与贪婪指数**：读取前一个UTC自然日的指数，候选正常区间为10–90至30–70；越界时降低仓位。当天指数不会用于当天收盘后的仓位，避免时间倒灌。
2. **全市场波动率**：计算六币等权篮子最近20日对数收益的年化波动率，超过候选上限60%–100%时降低仓位。
3. **市场宽度失衡**：计算20日收益为正的币种比例，转换为距50%中性宽度的失衡度；超过50%、67%或100%时降低仓位。

恐惧指数使用 [Alternative.me Crypto Fear & Greed Index](https://alternative.me/crypto/fear-and-greed-index/) 的官方历史API数据，范围为0（极度恐惧）至100（极度贪婪）。数据展示归属：**Data from Alternative.me Crypto Fear & Greed Index**。仓库保留2022-07-01至2026-07-15共1,475条日度记录及SHA-256清单。

候选网格共380组，只在开发区间排序。开发期胜出参数实际只采用“20日市场波动率超过60%时空仓”，没有采用恐惧指数或市场宽度；冻结后的结果是：

| 指标 | 第一阶段80/20 | 参考层开发胜出参数 |
| --- | ---: | ---: |
| 冻结验证盈利月 | 16 / 18（88.89%） | 14 / 18（77.78%） |
| 冻结验证年化 | 11.48% | 3.05% |
| 冻结验证最大回撤 | -11.30% | -17.51% |
| 2023至今盈利月 | 37 / 42（88.10%） | 36 / 42（85.71%） |
| 2023至今年化 | 19.57% | 23.24% |
| 2023至今最大回撤 | -21.81% | -19.06% |

参考层虽然提高了长区间年化并缩小长区间回撤，却同时降低冻结验证的盈利月比例、年化和回撤表现，所以发布检查失败。策略中心将参数保留为“仅观察”，默认关闭。

### 全部条件自适应研究

在单独参考层之后，又评估了440组组合级候选，同时使用：

- 20日市场宽度决定趋势仓位在5%–25%之间的动态配比。
- 前一日恐惧与贪婪指数和20日市场波动率缩放总风险。
- 上一日组合净值回撤触发3%–10%区间的动态减仓。
- 现有相对动量、趋势强度、月度锁定和动态杠杆继续生效。

只使用2023-01至2024-12进行筛选的低回撤胜出参数，在冻结验证取得16/18个盈利月、年化10.03%、最大回撤-10.40%；2023至今为37/42个盈利月、年化16.50%、最大回撤-18.43%。它明显降低回撤，但没有提高盈利月，收益也低于85/15配置，因此作为“低回撤观察档”保留，默认关闭。

440组中没有任何方案能同时提高盈利月、年化并改善验证和长期回撤。准确率优先发布规则因此采用明确容差：验证回撤最多放宽0.5个百分点、长期回撤最多放宽1.5个百分点，同时盈利月必须增加且两段年化均超过10%。85/15通过了这组规则：

| 指标 | 旧80/20 | 新85/15 | 变化 |
| --- | ---: | ---: | ---: |
| 冻结验证盈利月 | 16 / 18 | 17 / 18 | +1个月 |
| 冻结验证年化 | 11.48% | 12.28% | +0.80个百分点 |
| 冻结验证最大回撤 | -11.30% | -11.71% | -0.41个百分点 |
| 2023至今盈利月 | 37 / 42 | 38 / 42 | +1个月 |
| 2023至今年化 | 19.57% | 20.69% | +1.12个百分点 |
| 2023至今最大回撤 | -21.81% | -22.96% | -1.15个百分点 |

## 2023 年至今范围

新增范围为2023-01-01至2026-07-15。盈利月比例只统计已经结束的2023-01至2026-06共42个完整月份；2026-07截至15日的收益进入累计收益、年化和回撤，但不计入盈利月分母。

| 指标 | 结果 |
| --- | ---: |
| 完整盈利月 | 38 / 42 |
| 完整月份盈利比例 | 90.48% |
| 累计收益 | 94.49% |
| 年化收益 | 20.69% |
| 最大回撤 | -22.96% |
| 2023 | 3.50% |
| 2024 | 54.13% |
| 2025 | 26.46% |
| 2026 截至 07-15 | -3.59% |

长期范围的最大回撤明显高于冻结验证区间，说明扩大历史范围后风险并未维持在约-12%。2023年前五个月中有三个亏损月，2026年截至当前也为负收益；这些结果必须和90.48%的盈利月比例一起展示。

## 运行与发布边界

复现研究：

```powershell
npm.cmd run research:monthly-80
npm.cmd run research:all-conditions
```

脚本会同时输出开发区间、冻结验证区间，以及2023-01-01至行情清单最新完整UTC日的独立汇总。刷新行情时使用：

```powershell
npm.cmd run data:download
npm.cmd run data:verify
```

刷新官方恐惧指数历史数据：

```powershell
npm.cmd run data:fear-greed -- --start 2022-07-01 --end 2026-07-15
```

当前策略中心仍是 `CONFIG_ONLY`：启用只代表进入观察状态，不会自动开仓。正式执行器至少还需要：

- 同步或原子化处理多空两条腿，任一腿失败时立即停止扩大裸露方向风险。
- 使用 USDⓈ-M 标记价格、实际资金费率和 leverage bracket 重新计算风险。
- 校验价格步长、数量步长、最小名义价值和交易对状态。
- 将真实成交、滑点、手续费、资金费率和月度锁定事件写入不可变审计记录。
- 至少完成新的前向纸面交易期，再决定是否允许小额实盘。
